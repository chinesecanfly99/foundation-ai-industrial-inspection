# 05 部署与演示验收

## 部署目标

初稿先在当前 Windows 电脑使用独立环境和 CPU 完成图片输入到结果导出。本机 Gradio 默认仅本地访问；需要组员通过局域网或公网访问时另行配置与测试。GPU、macOS、Linux、云端托管分别是额外环境，未经实测不写“已支持”。

当前扩展为瓶口、金属螺母、瓷砖表面，每类单独模型与教学策略。2026-10-20首轮完成单瓶口83图评估、33项自动测试和9项浏览器检查，只代表旧版本。本轮实际验收以 `docs/STATUS.md` 和三类新证据为准，不沿用旧数量宣称通过。旧浏览器记录的非阻断进度404也不能作为忽略新错误的依据。

本轮完整自动测试93项通过（0失败/错误/跳过、25.244秒），记录为 `results/three_products/tests.xml`。各类完整test评估均已完成；本机浏览器17项功能检查通过，记录为 `results/three_products/ui/ui_smoke.json`（17:04 UTC+8，passed=true）。覆盖三类各主模型正常/缺陷与像素基线、样例数量和类别对应、热图解码、JSON/CSV一致、快速切换不串图、空/小/黑图错误恢复、高级合成隐藏与390px布局。仍有已记录的非阻断上传进度404及SSE中止；新电脑和整个网页断网需独立验收。

首次联网完成依赖、数据和预训练权重准备后，固定演示包应能够断网启动。像素基线应无需下载预训练权重。CNN 模型若缺少骨干文件，应报告准确缺失项，不偷偷改成随机权重。

## 演示脚本

1. 按 [README_演示.md](../README_演示.md) 展示产品类别、模型名称、实际设备、数据来源和规则版本。
2. 上传一张正常产品图：解释当前阈值下的建议及局限。
3. 每类上传一张明显缺陷图：展示原图、热图、候选区域和分数；检查对应模型与策略没有串类。
4. 展示微小/困难缺陷，说明不确定性与复核。
5. 使用可追溯的低光或模糊版本，演示质量门控和重拍建议。
6. 显示一条决策轨迹，逐项说明事实、阈值、规则与最终建议。
7. 下载 JSON、单图一行CSV和热图；切换产品/模型/样例后检查旧结果和下载不会残留，重新检测再导出。
8. 展示一个失败案例，说明改进和当前限制。

整段时长按课程正式要求调整，不继承 CV 参考包的固定分钟数。备用录屏注明为预录；录屏不替代当前程序运行验收。
