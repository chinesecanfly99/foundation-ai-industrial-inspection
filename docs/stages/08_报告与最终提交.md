# 阶段 08 报告与最终提交

## 目标

以真实证据完成符合当前课程要求的报告、展示和可复演提交包。

## 计划

报告角色维护初稿，全员核对自己模块。先用 [report_draft](../report_draft.md) 写方法与协议，结果部分从冻结实验文件生成；取得 rubric 后调整篇幅/格式/时长。最后全员演练问题、方法、失败和系统演示。

## 实施记录

2026-10-20：报告初稿已填入真实bottle数据支持数、两模型图像/定位指标、混淆矩阵、逐类计数和最终CPU时延，明确CNN仍漏13/63张异常，并非所有缺陷类型都改善。没有将外部论文或合成指标写作实测；处置有效性表因无独立标签保持待测。正式课程格式、完整研究与最终提交尚未完成。

## 验收

- [ ] 当前 rubric、日期和提交格式已核对。
- [ ] 报告每个数字能追溯到固定结果文件。
- [ ] 数据来源、许可、预训练模型和开源参考已引用。
- [ ] 简化模型与官方实现、视觉解释与规则解释区分清楚。
- [ ] 包含失败、校准限制、模拟规则和外部有效性边界。
- [ ] README、依赖、模型获取、样例与运行指引齐备。
- [ ] Git 提交不含大数据、缓存、虚拟环境或访问凭据。
- [ ] 一位其他成员从提交包完成复演。
- [ ] 全员参与演练并可回答主要方法与实验问题。

## 证据

最终报告/PPT、冻结代码提交、模型/清单/规则哈希、提交检查表、复演与演练记录。报告初稿本身不表示已完成最终提交。

## 未完成与下一步

初稿之后继续真实实验、业务标注、新电脑验收与课程格式确认。最终提交或公开仓库按用户明确范围执行，不从参考文档推断对外发布。
