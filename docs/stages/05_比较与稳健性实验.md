# 阶段 05 比较与稳健性实验

## 目标

用独立测试和逐图证据比较两种检测方案，并检查记忆库预算、受控扰动和 CPU 性能。

## 计划

实验角色在模型/阈值冻结后运行同一测试清单，生成图像混淆矩阵、AUROC、定位指标和失败图。随后在同一清单实施亮度/模糊扰动，保持阈值不变；可选记忆库预算消融每次只改一个因素。

## 实施记录

2026-10-20：已完成相同83张官方test的B01/M01，20正常/63异常。B01图像AUROC0.967460、Precision1.0、Recall0.761905、F1 0.864865，TN20/FP0/FN15/TP48；M01图像AUROC0.992063、Precision1.0、Recall0.793651、F1 0.884956，TN20/FP0/FN13/TP50。128×128像素AUROC分别0.891879/0.972858，异常图平均IoU分别0.250736/0.357199。完整性修复后的同配置复验指标完全一致；CPU热身后p50/p95为像素105.33/117.95毫秒、CNN118.06/130.30毫秒，热身调用分别117.42/2,008.79毫秒。这是预测调用时间，不是浏览器端到端耗时。
