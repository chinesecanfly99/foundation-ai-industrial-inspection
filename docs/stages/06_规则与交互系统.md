# 阶段 06 规则与交互系统

## 目标

把视觉结果变成可追踪事实与辅助建议，完成同一推理核心的 Gradio 图片演示。

## 计划

规则角色定义输入质量、临界分数、异常面积与关注区规则及优先级；关注区必须符合 bottle 实际视角。界面角色展示原图、异常图、测量值、规则 ID 与导出。两位成员独立标注模拟处置标签后，实验角色才能运行 D00/D01 效果对照。

## 实施记录

2026-10-20：规则与Gradio初稿已实现。`demo-policy-v1`采用中心归一化关注区、亮度/清晰度、分数临界区、面积规则与首个匹配优先；保存所有规则condition/selected轨迹及策略版本/哈希。规则6个处置边界与无效事实检查已通过自动测试。浏览器于11:50（UTC+8）完成9项功能检查，`passed=true`；没有独立业务处置标签。

已测范围：DOM、空图友好错误；合成正常/异常上传与热图/JSON；CSV对应最新图片；规则展开；黑图按强拒收证据判拒收；真实bottle正常/破损两图上传、热图与JSON；390px无整页横向溢出。图片complete/naturalWidth解码检查通过，page_errors为空。已修正本机代理把loopback自检转发导致502的问题，只添加本机地址代理排除；两次上传进度404保留为非阻断已知日志，不宣称控制台零错误。
