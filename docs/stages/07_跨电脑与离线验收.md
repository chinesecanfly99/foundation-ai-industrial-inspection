## 验收

- [ ] 干净环境只依照 README 成功安装。
- [ ] CPU 单图、规则与导出实际通过。
- [ ] 本机浏览器上传/预测/下载通过。
- [ ] 断网后固定样例无自动下载依赖。
- [ ] 中文/空格目录及无效输入处理正确。
- [ ] 连续至少 20 次操作资源与结果正常。
- [ ] 固定样例跨机差异在预先约定容差内。
- [ ] GPU/其他平台以独立结果记录 PASS/FAIL/NOT_TESTED。
