# 质检流程升级与课堂演示指南

默认界面为中文，顶部 English 按钮可切换到同一服务的英文界面。两个语言界面共用当前项目自己的记录；原中文版与英文独立副本仍分别保存环境、模型和记录，英文副本不上传 Git。

## 如何启动

先关闭占用同一端口的旧进程，再用原 start_windows.cmd 或 PyCharm 的 app.app 运行配置启动。中文版脚本默认 7860；若 PyCharm 参数使用 7861，浏览器和 PPT 链接也使用 7861。英文副本脚本使用 7863。切换语言会重新载入页面，未提交的选择会重置，已保存的记录与复核不受影响。

## 建议的课堂演示顺序

1. 打开“双模型同图对比”。瓶口保留正常、大缺口、小缺口、污染四类基础案例；选择后同时运行两种模型，比较热图、各自分数与阈值和处理建议。案例名称来自数据集标注，并不是模型自动识别的缺陷类别。小缺口可能被漏检，应保留真实结果作为失败分析，不修改显示数字来凑出预设结论。
2. 打开“画质挑战”，载入缺陷图，先用亮度 1.0、模糊 0 运行，再把亮度改成 0.1 重新检测。模型真实处理原图和变换图，对照平均亮度、清晰度、分数/阈值和处理建议。每一次改动都不一定改变最终建议，原图始终是对照。
3. 打开“生活案例演示”：模拟宿舍或家中的地砖巡检。默认裂纹图明确标注为公开 MVTec AD 样例，不冒充生活实拍或现场验证；可上传自己的地砖照片。拍摄视角、光照和材质变化会影响模型，结果需要独立人工核验。
4. 打开“批量质检”，载入四张演示图，或上传同类产品的 1-20 张图片。已成功上传但无法读取的图片会单独记为失败，其余继续处理。下载批次 CSV 和图片/报告 ZIP。单张 20 MB、整批 100 MB；在上传阶段被拒绝的文件不属于已完成批次的输入。
5. 打开“记录看板与人工复核”，按产品、来源和复核状态筛选，选择记录查看保存的输入与热图，填写复核人、结论和说明。人工结论追加保存，不覆盖模型原始结果，也不会自动训练模型。先生成筛选 CSV，再点击下载历史 CSV。

## 放入 PPT 的链接

先在演示电脑启动项目，再给 PPT 中的形状按钮添加下列超链接。链接会打开浏览器，并直接选中对应功能、定位到功能区；它不会把 Python 程序嵌入幻灯片。以下使用英文副本的默认端口：

| PPT 按钮 | 英文副本本机链接 |
| --- | --- |
| 双模型对比 | http://127.0.0.1:7863/?demo=compare |
| 画质挑战 | http://127.0.0.1:7863/?demo=challenge |
| 地砖生活案例 | http://127.0.0.1:7863/?demo=daily |
| 批量质检 | http://127.0.0.1:7863/?demo=batch |
| 历史与人工复核 | http://127.0.0.1:7863/?demo=history |

使用中文版时，将端口改成实际启动的 7860 或 7861 即可。若希望画面留在幻灯片里播放，把演示录成 MP4，通过“插入 → 视频 → 此设备”嵌入；保留现场按钮供互动使用。微软说明：https://support.microsoft.com/en-us/powerpoint/insert-and-play-a-video-file-from-your-computer 。只发送 PPT 不会附带本机服务，换电脑需要重新部署项目。

## 记录、复核与导出

私有数据保存在 results/workflow/inspections.sqlite3 和 records/。保存的输入是最长边不超过 1024 像素的 RGB 工作图，而非未经处理的原始照片。每条记录包含独立图片、热图、模型/规则信息与原始 AI 报告，复核则作为带时间戳的独立事件保存。

历史 CSV 在原始 AI 建议旁提供最新人工结论，多次复核保留在数据库与复核事件表里。批量 ZIP 固定保存检测时的快照，不会在之后复核时悄悄覆盖。整个 results/workflow/ 已排除在 Git 与交付源码包之外，不上传照片、复核人、说明、数据库或私有报告。两个项目副本不共用这份数据库。

## 结果应怎样讲

两种模型的原始分数尺度不同，应分别对照各自阈值；分数/阈值也不是缺陷概率。历史看板统计的是检测操作次数，包括重复图片、模型对比和画质变换，不是独立产品数或实验准确率。生活实拍和画质挑战不会直接计入现有性能实验；人工复核输入也不自动等于独立真实标签。

本次未修改已有模型参数、训练/校准/测试划分或规则的数值阈值，原实验仍为 315 张测试图、630 条模型预测。本次验证记录位于本机 results/workflow_verification/ 与 results/workflow_tests.xml；此前的单张检测和语言副本验收保留为历史记录。
